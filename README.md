Coimbatore-NEET-exam-Power-BI
Project Overview
    This project analyzes NEET student performance data to uncover insights into academic scores, eligibility categories, and career outcomes.
Tools & Technologies
	•	Excel (Data Cleaning & Dashboard)
	•	Power BI (Visualization)
Workflow
    Data collection → Data cleaning → Transformation → Analysis → Dashboard creation → Insight generation
Key Insights
	•	Identified subject-wise performance trends
	•	Analyzed eligibility for government vs private colleges
	•	Highlighted high scorers distribution and patterns
Outcome
     The dashboard helps stakeholders make data-driven decisions on student performance and admission strategies.
